# 💪 Workout Recommender App  
### Rule‑based AI logic that adapts to your mood, time, goals, location, and fitness level.

This is a personalized workout recommendation web app built with **Streamlit**.  
It uses a **rule‑based AI scoring engine** to suggest the most suitable workout type and generates **randomized routines** complete with **exercise images**.

---

## 🚀 Features

- Adaptive rule‑based AI logic  
- Mood‑aware workout recommendations  
- Time‑based intensity adjustments  
- Goal‑driven scoring engine  
- Home vs gym location logic  
- Fitness‑level personalization  
- Randomized routines for variety  
- Exercise images for visual guidance  
- Clean, responsive Streamlit UI  

---

## 🧠 How It Works

The app evaluates five inputs:

1. Mood  
2. Available time  
3. Fitness goal  
4. Workout location  
5. Fitness level  

These inputs are scored using a custom rule‑based engine.  
The highest‑scoring workout type is recommended, and a randomized routine is generated from a curated exercise pool.
